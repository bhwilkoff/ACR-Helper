2 · drive.file (the person chooses the file)

Google's file picker opens by itself in the side panel

The first time only, the person selects the committee's spreadsheet in the Google Picker (setFileIds). ACR Helper can then open that one file and nothing else in their Drive.

The picker lists the spreadsheet only if it is shared with the person, so the spreadsheet's own sharing decides who can use the add-on.
