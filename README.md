# ACR Helper

A Google Meet add-on that helps the people in a call make a decision
about each row of a spreadsheet, using the row's own data and other
sources. Only people who can open the spreadsheet with their own Google
account can use it.

Nothing is built yet. Start with:

- `AGENTS.md`: what the add-on is for, and how it is built (every
  agent reads it; `CLAUDE.md` and `GEMINI.md` import it).
- `SCRATCHPAD.md`: where things stand and the open questions.
- `docs/MEET-ADDON.md`: how a Meet add-on works, what was measured in
  real calls, and the one-time Google setup.

The method (skills in `.claude/skills/`, the process docs in `docs/`)
comes from UniversalAppTemplate, with everything about native apps left
out.
