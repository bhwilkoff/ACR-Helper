Privacy policy

Last updated November 23, 2026.

ACR Helper is a Google Meet™ add-on made by Ben Wilkoff. This page says what it reads, what it writes, and where information goes.

What ACR Helper asks Google for

  • Your name and email address (the openid, email, and profile permissions), to show the committee who has voted and to name the person who recorded a decision.
  • Access to only the files you choose for it (the drive.file permission). The first time you open ACR Helper, Google's own file picker asks you to choose the committee's spreadsheet; ACR Helper can open that spreadsheet and nothing else in your Google Drive™. It uses it to check that you can open it, to read its rows, to keep a hidden tab in it holding the key that encrypts the call's messages, and, for the chair, to write the committee's decision and a note into the applicant's row.

Where spreadsheet information goes

  • Rows are read from Google directly into your own browser, inside Meet, and shown only to you. They are never sent to a server run by ACR Helper, never stored in a database, a log, or your browser's storage, and never shared with anyone else.
  • Everyone in the call sees the same applicant because each person's own add-on reads the row itself, with that person's own Google permission.
  • The access token Google gives your browser stays in memory and is gone when the add-on closes.

Votes and messages between add-ons

To keep everyone on the same applicant and to collect votes, add-ons in the same call send each other short messages through Supabase Realtime, a message relay. Every message is encrypted in your browser before it leaves, with a key that only people who can open the spreadsheet can read; the relay sees only scrambled data and stores nothing. Votes are sealed so that only the chair's add-on can open them, and only when the chair reveals them. Votes are never stored anywhere.

What is kept in your browser

Only the email address you last signed in with, so Google can skip asking which account to use. Nothing from the spreadsheet is kept.

How sensitive data is protected

Applicant information in the spreadsheet is sensitive. ACR Helper protects it in these ways:

  • No copies. ACR Helper runs no server and no database of its own. Spreadsheet data is never stored, logged, cached, or backed up by ACR Helper; it exists only on your screen while the add-on is open, and is gone when you close it.
  • Encryption in transit. Every connection, to Google's servers and to the message relay, uses HTTPS or secure WebSockets (TLS). Messages between add-ons are also encrypted end to end in your browser with AES-256-GCM before they are sent, so the relay cannot read them. Votes are additionally sealed with an elliptic-curve key (ECDH P-256) so that only the chair's add-on can open them, and only on reveal.
  • Access control by Google. Every read and write is made with your own Google permission, and Google checks the spreadsheet's sharing on every request. ACR Helper keeps no list of who is allowed in; being removed from the spreadsheet removes access the next time the add-on opens.
  • Least access. ACR Helper can open only the spreadsheet you choose for it in Google's own file picker, and no other file in your Google Drive™.
  • Short-lived credentials. Google's access token is held only in memory, expires within an hour, and is never written to storage, logs, or a server. ACR Helper never sees your password.
  • Hardened pages. The add-on's pages load code only from ACR Helper's own site and Google, under a strict Content Security Policy, and send no referrer to links they open. There are no analytics, advertising, or tracking scripts.
  • Retention and deletion. ACR Helper retains no user data, so there is nothing to delete on our side. The decision and note the chair records live in the committee's own spreadsheet, under the committee's control.
  • Reporting a problem. If you believe information has been exposed, write to the contact below; we will respond, investigate, and tell affected users what happened.

Google API Services User Data Policy

ACR Helper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Information from Google is not used for advertising, not sold, not transferred to others except as described above to run the add-on, and not used to train any artificial intelligence or machine learning model.

Removing access

You can remove ACR Helper's access at any time at myaccount.google.com/permissions. Being removed from the committee's spreadsheet also ends your access to everything in ACR Helper the next time it opens.
